## 这是什么

如果你同时用多个 AI API 中转站（New API、One API、以及各种 fork），最烦的就是每个站点都要打开一次网页才能看余额和用量。**AI 中转站用量看板**把这些全部聚合到 Chrome 侧边栏：

- 各站点**实时余额**与**今日用量**一览
- 按**币种分组**汇总，绝不把 ¥ 和 $ 混在一起
- 自动/手动采集，过期自动提醒
- 本地历史库，可看真实趋势，不依赖“估算”
- 导出/导入站点配置，迁移方便

> 核心红线：**不存 Token、不存 Cookie、不上传凭证、不模拟数据**。没有精确接口的站点，今日用量与趋势只显示 `—`，绝不编造。

## 核心特性

| 特性 | 说明 |
|------|------|
| **Cookie 会话采集** | 只复用你已经登录的站点 Cookie，插件本身不保存密码或 Token |
| **适配器模板** | 内置 New API / One API 兼容适配器，并支持自动探测真实接口路径 |
| **按币种分组** | 总余额按 USD / CNY / JPY 等币种分别展示，不跨币种相加 |
| **过期提醒** | 登录态失效时自动通知，点击即可跳转到原站重新登录 |
| **本地历史库** | 快照、日聚合保存在本机 IndexedDB，长期可查 |
| **导入导出** | 配置导出默认剔除凭证，导入时做 schema 校验与转义 |
| **最小权限** | 站点域按需动态申请，删除站点即撤销对应 `host_permissions` |
| **暗色/亮色主题** | 支持白天 / 黑夜 / 跟随系统 |

## 安装与加载

1. 克隆仓库：
   ```bash
   git clone https://github.com/shanyuyulai/AI_Relay_Usage_Dashboard.git
   cd AI_Relay_Usage_Dashboard
   ```
2. 安装依赖：
   ```bash
   unset HTTP_PROXY HTTPS_PROXY
   npm install
   ```
3. 类型检查与构建：
   ```bash
   ./node_modules/.bin/vue-tsc --noEmit
   ./node_modules/.bin/vite build
   ```
4. 打开 Chrome `chrome://extensions/`，开启右上角「开发者模式」。
5. 点击「加载已解压的扩展程序」，选择生成的 `dist/` 文件夹。
6. 点击工具栏扩展图标，或按 Chrome 侧边栏快捷键打开插件。

> ⚠️ 注意：仓库根目录即为 Vite 工程目录，构建命令请在本仓库根目录执行。

## 使用方法

### 添加第一个中转站

1. 先在普通标签页登录你要接入的中转站（确保 Cookie 会话有效）。
2. 打开插件侧边栏，点击「设置」进入 Options 页面。
3. 点击「＋ 添加站点」，填写名称与根地址（如 `https://api.example.com`）。
4. Chrome 会弹出权限申请，点击「允许」授予该 origin 访问权。
5. 点击「授权测试」验证登录态；通过后即可看到余额与用量。
6. 返回侧边栏，点击「⟳ 全部刷新」即可看到最新数据。

### 日常使用

- **手动刷新**：侧边栏顶部「⟳」按钮立即采集全部站点。
- **自动采集**：在 Options「数据采集库」设置间隔（关闭 / 5 / 15 / 30 / 60 分钟 / 自定义）。
- **看趋势**：点击站点卡片进入详情，查看余额折线、模型分布与当日使用趋势。
- **跳转原站**：每个卡片都有「打开站点」按钮，一键回到原站充值或查账单。
- **使用说明**：Options 页面右上角「❔ 使用说明」按钮可打开本说明弹窗。

## 隐私与安全

这是本项目的硬性红线，任何情况下都不会妥协：

- **不存密码 / 不存 Token / 不存 Cookie 原文**：M1 仅复用站点 Cookie 会话；Cookie 在请求时实时读取，绝不写入本地库、绝不回传。
- **绝不上传 API Key**：插件不会读取、收集或上传你的 API Key、Token、Cookie 等任何凭证。
- **数据只保存在本地**：所有余额、用量、快照、日聚合均保存在你本机的 IndexedDB 与 `chrome.storage.local` 中，不做任何云端同步。
- **凭证严格隔离**：凭证按站点 ID 隔离存取，接口签名从类型上消灭「全局默认回退」，避免把 A 站凭证发给 B 站。
- **最小权限申请**：manifest 只声明基础权限；站点域全走可选权限，添加即申请、删除即撤销。
- **导出剔除凭证**：配置导出走白名单字段序列化（不含任何凭证）；导入时做 schema 校验与 HTML 转义防 XSS。
- **审计可追溯**：每次真实快照记录采集通道、接口版本、响应哈希（脱敏）、数据质量状态，便于判断数据可信度。

## 常见问题

**Q：某个中转站显示「需重新授权」怎么办？**
> 说明该站点的登录态（Cookie）已失效。请在普通标签页打开并重新登录该中转站，回到插件重新授权即可。插件不会替你保存密码。

**Q：为什么有的站点没有「今日用量 / 趋势」？**
> 该站点没有可被核验的用量 / 日志接口，或接口路径与内置适配器不匹配。这是刻意的红线——绝不用余额差分冒充消耗、绝不编造数据。此类站点只展示余额与累计值。

**Q：总余额为什么不把所有币种加在一起？**
> 未接入汇率前，跨币种相加没有意义。仪表盘会按币种分别展示（如 ¥128.50 · $12.30）。

**Q：关掉浏览器后还会自动采集吗？**
> Chrome 的 Service Worker 会被系统休眠。插件用 `chrome.alarms` 周期性唤醒补采，并在你打开侧边栏时对比上次更新时间补采。

**Q：支持 Edge 吗？**
> 插件基于 Manifest V3 + sidePanel API，理论上兼容 Edge 116+。建议优先在 Chrome 上使用。

**Q：我的数据会传到云端吗？**
> 不会。所有数据均只保存在你本机，不做云端同步。
