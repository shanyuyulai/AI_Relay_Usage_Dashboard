AI 中转站用量看板

AI Relay Usage Dashboard · Chrome 侧边栏插件

一个侧边栏，一眼看清你所有 AI API 中转站的余额、今日用量与真实历史趋势。无需来回切换标签页，无需任何绕过限制的插件。

Chrome / Edge MV3 本地优先 · 隐私安全 真实数据 · 禁模拟

1这是什么

当你同时使用多个 Claude / GPT API 中转站（如 RayinAI、Hubway 等）时——

每个中转站的余额、Token 用量、用量趋势都分散在各自的网页后台里。想看一眼总账，就得开一堆标签页来回切。这个插件把这些信息聚合成一个 Chrome 侧边栏仪表盘：

  • 📊 总览：所有站点的总余额（按币种分组）、今日总 Token、今日总请求、站点在线数。
  • 🏷️ 站点卡片：每个中转站的余额、今日使用、今日 Token / 请求、API 往返耗时，以及近 7 天迷你趋势。
  • 📈 趋势详情：单站点近 7 / 30 / 90 天的 Token 与请求趋势、余额曲线、按模型消耗分布。
  • 🕒 自动采集：后台定时（默认 30 分钟）静默刷新，打开侧边栏时也能一键同步。
设计红线今日用量与历史趋势只能来自站点真实的 usage / log 接口，绝不拿余额做差分冒充消耗，绝不写入任何模拟数据。没有精确用量接口的站点，只显示余额、不展示用量趋势（显「—」），宁缺毋滥。

2核心特性

围绕「真实、安全、好用」三个目标构建。

🔐

Cookie 会话复用

直接复用你已经登录的中转站 Cookie，不保存密码、M1 阶段不存储任何 Token 明文。

🧩

适配器模板

内置 New API / One API 系模板，覆盖绝大多数中转站；新站基本只需填 URL。

💱

按币种分组

总余额按币种分别展示，不跨币种相加（未接入汇率前相加无意义）。

🔔

登录态过期提醒

会话失效时发浏览器通知并标「需重新授权」，引导你去原站重新登录。

🗂️

本地历史账本

IndexedDB 保存原始快照与按日聚合；原始快照保留可配（默认 90 天），按日数据长期留存。

📤

配置导入导出

站点配置可导出 / 导入，导出默认剔除所有凭证，导入做校验防 XSS。

🛡️

最小权限

站点域权限按你填写的地址逐个动态申请，不用 <all_urls> 一次性全开。

🌗

浅色 / 深色 / 自动

跟随系统或手动切换主题；侧边栏布局紧凑，首屏读缓存即出。

3界面一览

侧边栏仪表盘（左）与设置页（右）的整体观感。

侧边栏仪表盘：总览 4 卡 + 站点卡片列表
设置页：站点管理 / 权限 / 数据维护

4安装与加载

开发者模式加载已构建的扩展包（dist/）。

构建扩展

在项目根目录运行 vite build，产物输出到 dist/ 目录。

打开扩展管理页

Chrome 地址栏输入 chrome://extensions，打开右上角「开发者模式」。

加载已解压的扩展

点击「加载已解压的扩展程序」，选择构建好的 dist/ 文件夹。

固定到工具栏

点击扩展图标旁的「拼图」按钮，将「AI 中转站用量看板」固定到工具栏。

打开侧边栏

点击工具栏图标，或右键图标选「打开侧边栏」，即可看到仪表盘。

提示重新构建后，回到 chrome://extensions 点击该扩展的「刷新」按钮即可加载最新版本，无需重新加载文件夹。

5添加你的第一个中转站

核心操作在「设置页」完成。整个过程只复用你已有的登录态，不要求你提供任何密码或 Token。

先在浏览器登录中转站

在普通标签页打开并登录你的中转站后台（如 https://rayinai.example），确保 Cookie 会话有效。

打开设置页 → 添加站点

点侧边栏右上角 ⚙，或工具栏右键扩展选「选项」。点「添加站点」填写信息：

  • 名称：随意，如「RayinAI」。
  • 面板 URL：中转站根地址（用于归一化授权域）。
  • 适配器：绝大多数选「New API 系」；fork 站点可选对应模板或「通用」。
  • 货币：站点结算币种（CNY / USD / JPY / EUR），用于正确分组展示。
  • 颜色：站点卡片标识色。

授权（动态申请域权限）

保存后插件按 URL 归一化为具体 origin，弹出 Chrome 权限请求，点「允许」。它会复用你已登录的 Cookie 会话，不会读取密码。

测试授权 / 首刷

点「保存并测试授权」：插件在该 origin 下用 fetch(credentials:'include') 试采真实接口。成功后保存配置并首刷；失败则标「需重新授权」。

回到侧边栏查看

打开侧边栏 → 点右上角 ⟳ 全部同步，几秒内即可看到真实余额与今日用量。

如果某站今日用量显示「—」说明该站点没有可被核验的用量 / 日志接口（或接口已变更）。这是刻意设计的红线：绝不用余额差分冒充消耗、绝不编造数据。此类站点只展示余额与累计值，趋势图留空。

6日常使用

装上之后，你几乎只需要偶尔看一眼侧边栏。

⟳

手动同步

侧边栏右上角 ⟳ 刷新全部；每张站点卡右下角「刷新 ⟳」可单独刷新某一站。

🕒

自动采集

后台按设定间隔（默认 30 分钟）静默采集；Service Worker 休眠时由 chrome.alarms 唤醒。

📈

趋势详情

点站点卡片进入详情：近 7/30/90 天 Token 与请求趋势、余额曲线、按模型消耗分布。

↗

跳转原站

卡片上的「打开原站 ↗」一键在新标签打开对应中转站后台，不做 iframe 嵌页。

🔔

过期通知

会话失效时发浏览器通知并标黄「需重新授权」，引导你去原站重新登录后再刷新。

🌗

主题切换

侧边栏右上角太阳/月亮图标循环切换 浅色 → 深色 → 跟随系统。

7工作原理

一次采集的数据流向：定时 / 手动触发 → 采集编排 → 适配器取数 → 归一化快照 → 入历史库 → 广播刷新。

架构与一次采集的数据流
为什么不用 iframe / 绕限制插件早期原型依赖 CORS Unblock、ignore-x-frame-options 等插件才能抓数据，脆弱且不安全。本方案用 MV3 合法的 host_permissions 直接跨域请求真实接口，全程无需任何第三方绕限制插件，也不嵌 iframe。

8隐私与安全

这是本项目的硬性红线，任何情况下都不会妥协。

🚫

不存密码 / 不存 Token

M1 仅复用站点 Cookie 会话；Cookie 在请求时实时读取、绝不写入本地库、绝不回传。Token 模式后置，且明确「关浏览器后定时采集不可用」。

🧱

凭证严格隔离

凭证按站点 ID 隔离存取，接口签名从类型上消灭「全局默认回退」，杜绝把 A 站凭证发给 B 站。

🔒

最小权限申请

manifest 只声明 storage / alarms / sidePanel / tabs；站点域全走可选权限，添加即申请、删除即撤销。

📦

导出剔除凭证

配置导出走白名单字段序列化（不含任何凭证）；导入时做 schema 校验与 HTML 转义防 XSS。

🧮

渲染全程转义

站点名 / URL 等一律文本插值（Vue 默认转义），禁止 v-html 渲染外部数据；MV3 合规，无远程代码、无 eval。

🪪

审计可追溯

每次真实快照记录采集通道 / 接口版本 / 响应哈希（脱敏）/ 数据质量状态，便于判断数据可信度。

开源与隐私承诺
本项目代码已在 GitHub 开源：github.com/shanyuyulai/AI_Relay_Usage_Dashboard。
插件绝不上传你的 API Key、Token、Cookie 或任何站点凭证；所有余额 / 用量 / 快照数据均只保存在你本机的 IndexedDB 与 chrome.storage.local 中，不做云端同步，也不向任何第三方服务器发送数据。

9常见问题

使用中可能遇到的疑惑。

某个中转站显示「需重新授权」怎么办？
说明该站点的登录态（Cookie）已失效。请在普通标签页打开并重新登录该中转站，回到侧边栏点对应卡片的「刷新 ⟳」即可恢复。插件不会替你保存密码。
为什么有的站点没有「今日用量 / 趋势」？
该站点没有可被核验的用量 / 日志接口，或接口路径与内置适配器不匹配。这是刻意的红线——绝不用余额差分冒充消耗、绝不编造数据。此类站点只展示余额与累计值，趋势区域留空显「—」。
总余额为什么不把所有币种加在一起？
未接入汇率前，跨币种相加没有意义。仪表盘会按币种分别展示（如 ¥128.50 · $12.30），并明确标注「不跨币种相加」。
关掉浏览器后还会自动采集吗？
Chrome 的 Service Worker 会被系统休眠。插件用 chrome.alarms 周期性唤醒补采，并在你打开侧边栏时对比上次更新时间补采，尽量不漏数据；Cookie 会话同样受浏览器存活限制。
支持 Edge 吗？
插件基于 Manifest V3 + sidePanel API，理论上兼容 Edge 116+。建议优先在 Chrome 上使用，Edge 可作为加分项验证。
我的数据会传到云端吗？
不会。所有快照、日聚合都保存在你本机的 IndexedDB（chrome.storage.local），不做任何云端同步（一期）。
